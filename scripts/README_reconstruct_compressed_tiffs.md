# Reconstruct Compressed TIFF Sequences

The `reconstruct_compressed_tiffs.py` helper restores per-frame TIFF sequences from the
HEVC videos generated by the batch compression notebook.

## Requirements

- Python 3.9+
- `ffmpeg` available on your system `PATH`
- Python dependencies: `numpy`, `Pillow` (both already used elsewhere in this repo)

## Usage

From the repository root:

```bash
python scripts/reconstruct_compressed_tiffs.py --quality 90
```

Key options:

- `--quality`: Select the quality level to reconstruct (e.g. `90`, `95`, `100`).
- `--limit-folders`: Optional list of original folder names to restrict processing.
- `--ct-base-path`: Override the root directory that contains the original `ct_files`.
- `--csv-path`: Path to the `batch_processing_results.csv` file produced by the notebook.
- `--overwrite`: Replace existing reconstructed TIFFs when rerunning the script.

For example, to rebuild only `file_12_extracted` at quality 90:

```bash
python scripts/reconstruct_compressed_tiffs.py --quality 90 --limit-folders file_12_extracted
```

## Output Structure

For each dataset, the script:

1. Loads the recorded dynamic range from the CSV results.
2. Decodes the compressed video stream back into normalized frames.
3. Restores the original value range.
4. Writes each frame to the folder `ct_files/<name>_compressed_<quality>` (e.g. `file_12_compressed_90`) using the original TIFF filenames.

This preserves the original frame naming convention so downstream tools can operate on the
reconstructed data without changes.
