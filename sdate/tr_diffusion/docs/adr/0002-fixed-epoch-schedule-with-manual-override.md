# Fixed per-round epoch schedule (5 then 2, warm-started) with manual override, not automatic early stopping

Standing project guidance ([[feedback_training_steps_not_epochs]]) is to judge convergence by step count/loss curve rather than a fixed epoch target. For Annealed-N2N's round loop we deliberately deviate: round 0 trains from scratch for 5 epochs, every subsequent round warm-starts from the prior round's weights and trains for a fixed 2 epochs, with no automatic plateau detection.

We chose this because the round denoiser is warm-started (not reinitialized) each round, and prior ablations in this codebase's closest analogous warm-started loop showed 2 epochs was already sufficient to produce good results after the first round. A fixed schedule is also simpler to reason about across 10 rounds than per-round adaptive stopping. There is deliberately no held-out validation split — all data is used for training every round — so the convergence signal is the per-round projection-domain PSNR/SSIM against the reference frame (already computed as the trajectory diagnostic), not a train/val loss curve. The trade-off is real: if a round clearly hasn't converged in 2 epochs (PSNR/SSIM still trending up sharply round-over-round rather than plateauing), the fixed schedule will silently undertrain it. We're accepting that risk in exchange for simplicity, on the condition that the per-round PSNR/SSIM trajectory is actually watched and any round's epoch count is bumped by hand if it looks unconverged — this is a manual safety valve, not an automated one. Revisit if warm-starting turns out to over-retain blur from earlier rounds (a risk flagged separately), since a switch to cold-restart-per-round would likely also need this epoch budget reconsidered.
